# ศูนย์ปฏิบัติการกลุ่มจังหวัด 4

ระบบรายงานการบริหารงานแบบกลุ่มจังหวัด (กลุ่มจังหวัดภาคตะวันออก 2) ปีงบประมาณ พ.ศ. 2570
สำหรับสำนักงานยุติธรรมจังหวัดปราจีนบุรี นครนายก สระแก้ว จันทบุรี และตราด

## โครงสร้าง

| ส่วน | ที่อยู่ | ทำหน้าที่ |
|---|---|---|
| หน้าเว็บ | `public/` | หน้าระบบทั้งหมด (สร้างไว้แล้ว ไม่ต้อง build) |
| ล็อกอิน | Netlify Identity | บัญชี Google หรืออีเมลและรหัสผ่าน |
| ฐานข้อมูล | Netlify Blobs (store `opcenter`) | เก็บข้อมูลเป็นเอกสาร 1 คีย์ต่อ 1 เอกสาร |
| API | `netlify/functions/api.mjs` (`/api/*`) | ตรวจสิทธิ์ทุกครั้งที่อ่าน/เขียน |
| ตัวเชื่อมฝั่งหน้าเว็บ | `src/nf-client.js` → `public/vendor/nf.js` | หน้าเข้าสู่ระบบ, ดึงข้อมูลทุก 10 วินาที, ดาวน์โหลดไฟล์ |

## สิทธิ์

- **ผู้ดูแลระบบ**: อีเมลในตัวแปร `ADMIN_EMAILS` (คั่นด้วยจุลภาค) หรือผู้ใช้ที่มี role `admin` ใน Netlify Identity
- **ผู้รายงานข้อมูล**: ผู้ใช้ที่ผู้ดูแลอนุมัติแล้ว แก้ไขได้เฉพาะสำนักงานของตน
- **ผู้ประสานศูนย์ปฏิบัติการ**: แก้ไขคำนำ ข้อเสนอแนะ กิจกรรม/งบประมาณ และกำหนดส่งได้เพิ่ม
- ผู้ที่เข้าสู่ระบบแล้วแต่ยังไม่อนุมัติ: ดูได้อย่างเดียว

## ตั้งค่าครั้งแรกใน Netlify

1. Project configuration › Identity › **Enable Identity**
2. Registration preferences: **Open** · External providers: เพิ่ม **Google**
3. Environment variables: `ADMIN_EMAILS` = อีเมลผู้ดูแล

## แก้ไขโค้ดหน้าเว็บ

ต้นฉบับหน้าเว็บอยู่ในโปรเจกต์หลัก แล้ว build ออกมาเป็น `public/index.html`
แก้ `src/nf-client.js` แล้วรัน `npm run build:client`
